# Mate Control 🧉

MateControl is a loan management system designed for university student centers that lend mate kits to students.

The project aims to replace the manual records currently kept on paper or in spreadsheets with a centralized system for managing students, equipment, and loans.

Students register their information once, for subsequent loans, an operator can find the student using their phone number and reuse their registered information without entering it again.

Each mate kit has a unique identification number. Every loan links one registered student to one specific kit, recording when the kit is borrowed and when it is returned. The system keeps a history of loans and tracks whether each kit is available, currently borrowed, or out of service.

MateControl is intended to make the lending and return process faster, reduce duplicate data entry, and provide student centers with a single, organized record of their students and equipment.
